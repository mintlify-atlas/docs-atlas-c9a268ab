The CocoaPods Specs repository is the centralized registry powering dependency resolution for iOS and macOS projects worldwide. With over 100,000 library podspecs served via CDN, it provides fast, reliable access to the entire CocoaPods ecosystem. Whether you're adding a dependency to your project or publishing your own library for the community, this is where it all starts.

## What is the Specs repo?

The CocoaPods Specs repo is a Git repository containing the metadata — called podspecs — for every publicly available CocoaPods library. When you run `pod install`, CocoaPods uses this registry to locate the exact version of each dependency your project needs.

## Publishing to the registry

<Note>
The Specs repo does not accept pull requests. All pod submissions must go through **CocoaPods Trunk** using the `pod trunk push` command.
</Note>

<Steps>
  <Step title="Create your podspec">
    Write a `.podspec` file describing your library's metadata, source, and dependencies.
  </Step>
  <Step title="Set up Trunk access">
    Register a CocoaPods Trunk account with your email to get publishing credentials.
  </Step>
  <Step title="Push to the registry">
    Run `pod trunk push YourLibrary.podspec` to validate and publish your pod.
  </Step>
  <Step title="Manage your pod">
    Use `pod trunk deprecate` or `pod trunk delete` to manage released versions.
  </Step>
</Steps>
