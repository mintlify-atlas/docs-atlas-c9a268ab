---
title: "Quickstart: install CocoaPods and add your first pod"
description: "Install CocoaPods, create a Podfile for your Xcode project, add your first pod dependency, and run pod install to get up and running."
---

This quickstart walks you through installing CocoaPods, setting up a `Podfile` in your Xcode project, adding a dependency, and running your first `pod install`. By the end you will have a working `.xcworkspace` with your pod linked and ready to use.

<Note>
  CocoaPods resolves specs from a CDN, so you do not need to clone the full Specs repository. The minimum supported CocoaPods version is **1.0.0**; the latest release is **1.16.1**.
</Note>

<Steps>
  <Step title="Install CocoaPods">
    CocoaPods is distributed as a Ruby gem. Install it with:

    ```bash
    sudo gem install cocoapods
    ```

    Verify the installation:

    ```bash
    pod --version
    ```
  </Step>

  <Step title="Initialize a Podfile">
    Navigate to the root directory of your Xcode project (the folder containing your `.xcodeproj` file) and run:

    ```bash
    pod init
    ```

    This creates a `Podfile` with a basic template pre-filled with your project's targets.
  </Step>

  <Step title="Add a pod to your Podfile">
    Open the `Podfile` in your editor and add a pod inside the target block. The example below adds [Alamofire](https://github.com/Alamofire/Alamofire), a popular networking library:

    ```ruby
    # Podfile
    platform :ios, '13.0'
    use_frameworks!

    target 'MyApp' do
      pod 'Alamofire', '~> 5.0'
    end
    ```

    The `~> 5.0` operator means CocoaPods will use any version from `5.0` up to (but not including) `6.0`.
  </Step>

  <Step title="Install the pod">
    From the same directory as your `Podfile`, run:

    ```bash
    pod install
    ```

    CocoaPods fetches the podspec from the CDN, downloads the library source, and generates an `.xcworkspace` file that includes your project alongside the installed pods.
  </Step>

  <Step title="Open the workspace">
    Always open the `.xcworkspace` file going forward — not the `.xcodeproj`:

    ```bash
    open MyApp.xcworkspace
    ```

    Your pod is now linked and you can import it in your Swift or Objective-C files.
  </Step>
</Steps>

<Tip>
  To update your pods to newer compatible versions, run `pod update`. To update a single pod, run `pod update Alamofire`.
</Tip>
